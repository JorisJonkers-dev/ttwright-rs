# Security Policy

## Reporting A Vulnerability

Do not report vulnerabilities in public issues, pull requests, discussions, or commit comments.

Report suspected vulnerabilities privately, through GitHub's private vulnerability reporting
on this repository or by mail to:

- `security@jorisjonkers.dev`

Include:

- affected repository and commit, tag, or version
- concise impact description
- reproduction steps or proof of concept
- relevant logs with secrets and private data removed


## Handling

Security reports are reviewed privately. Public disclosure, issue creation, and fix details are
coordinated by Joris Jonkers after the risk is understood and a remediation path exists.

## Supported Code

Only the current default branch and the latest release are in scope.
